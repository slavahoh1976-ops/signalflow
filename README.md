# SignalFlow — схемы видеосигнала

Редактор схем видеосигнала для аппаратных в духе draw.io, но с портами, проверкой совместимости и кабельным журналом.

**Открыть:** https://slavahoh1976-ops.github.io/signalflow/

## Установка как программы (Windows / macOS)
Откройте ссылку в Chrome или Edge → значок «Установить» в адресной строке (или меню ⋮ → «Установить SignalFlow»).
Появится ярлык на рабочем столе / в Launchpad, программа работает без интернета.

## Возможности
- База устройств с фото: «＋ Своё устройство», перетаскивание фото на библиотеку, Ctrl+V для вставки фото
- Порты с типами сигналов (12G/3G-SDI, HDMI, DP, оптика, Ethernet/NDI, Genlock, аудио…)
- Кабель от порта к порту; на устройство — порт подбирается сам; в пустоту — предложит совместимое устройство
- Проверка совместимости, вставка конвертера в разрыв, автонумерация кабелей
- Зоны (помещения/рэки), листы, кабельный журнал и спецификация (CSV для Excel), экспорт PNG/SVG, печать/PDF
- Быстрая работа на больших схемах (1000+ устройств)

## Данные
Схема и база устройств хранятся в браузере (IndexedDB). Для надёжности сохраняйте проект в файл — Ctrl+S (`.sflow.json`), базу — «⇩ База».

## Разработка
Исходники в `src/`, сборка в один файл: `python3 src/build.py` → `index.html`.
